FOOD LAB — static website (GitHub Pages)

Upload the CONTENTS of this folder (index.html, assets, css, js ...) to a GitHub repo, then
Settings > Pages > Deploy from a branch > main / (root) > Save.

To change products or prices: edit js/products.js.
To change the WhatsApp number: edit "WA" near the top of the helpers section in js/main.js,
and the visible number text in index.html.
